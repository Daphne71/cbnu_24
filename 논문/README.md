# 자동차 H/Shaft 이종품 검출을 위한 모델 성능 분석 및 경량화 모델 제시

개요 (Overview)

스마트 공장의 확산으로 실시간 AI 기반 품질 검사의 중요성이 지속적으로 증가하고 있다.
그러나 실제 산업 현장에서는 고성능 연산 장비 도입에 따른 비용 및 인프라 제약으로 인해,
연산 효율이 높은 경량 딥러닝 모델에 대한 요구가 커지고 있다.

본 연구는 **자동차 H/Shaft Anomalous Part Detection(이종품 검출)**을 대상으로,
표준 딥러닝 모델과 다양한 경량 모델의 성능을 비교·분석하고,
산업 현장에 적용 가능한 경량 이미지 분류 모델을 제시하는 것을 목표로 한다.

🎯 연구 목적

- 자동차 H/Shaft 이종품 검출을 위한 딥러닝 기반 분류 모델 성능 분석
- 표준 모델과 경량 모델 간 성능–효율 트레이드오프 비교
- MobileNetV2 기반 구조 개선을 통한 경량 모델 설계
- 엣지 및 임베디드 환경에 적합한 실용적 품질 검사 모델 제시

🧠 연구 방법
기본 CNN 모델 : ResNet50, VGG16
경량 모델 : MobileNetV2, EfficientNet-B0, DenseNet121, MobileViT-S

- 기본 CNN 모델과 경량 모델 비교 후 기준 모델 선정

경량 모델 중 기준 모델: MobileNetV22
- 경량화 기법
Width Multiplier(α) 조정 (α = 1.0, 0.75, 0.5, 0.25)
Depth 축소 (Bottleneck 블록 제거)
Compact 설계 (Width + Depth 동시 축소)

- 평가 지표
정확도(Accuracy)
파라미터 수(Parameters, M)
모델 크기(Model Size, MB)
연산량(FLOPs, G)

혼동행렬(Confusion Matrix)

주요 연구 결과

Width Multiplier 축소는 파라미터 수와 FLOPs 감소에 효과적이나, α ≤ 0.5부터 정확도가 급격히 저하됨
Depth 축소 모델은 연산량 감소에도 불구하고 높은 정확도를 유지하여 효율성이 우수함
Compact 모델은 극단적인 경량화를 달성하였으나, 일부 정확도 저하가 발생함
MobileNetV2-Depth 축소 모델은 정확도와 연산 효율 간 가장 균형 잡힌 성능을 보이며,
산업용 비전 시스템에 가장 적합한 모델로 평가됨

산업적 의의

파라미터 수 감소는 모델 크기 축소로 직접 연결되어 메모리 제약 환경에서 배포 용이성 향상
엣지, 임베디드, IoT 기반 검사 장비에서도 실시간 추론 가능
자원 제약 환경에서도 안정적인 AI 품질 검사 시스템 구축 가능성을 입증
